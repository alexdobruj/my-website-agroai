# AgroAI Holding — сайт + MVP закрытого агро-маркетплейса

Отдельный проект агро-консалтингового холдинга (не пересекается с amazon-tool-suite).

- `docs/STRATEGY.md` — костяк бизнеса: два направления, цепочка, модели, дорожная карта, открытые вопросы
- `docs/LINKEDIN.md` — тексты для профиля основателя и страницы компании, контент-план

## Что внутри

Сайт двуязычный: **украинский** — основной (корень `/`), **английский** — в `/en/` (для покупателей и партнёров из ЕС). Переключатель UA/EN в шапке ведёт на ту же страницу другого языка; в `<head>` прописаны `hreflang`. Общие тексты шапки/подвала, справочники и список областей — в `public/js/main.js`, логика форм — в `public/js/join.js` и `public/js/market.js` (общие для обоих языков). Админка внутренняя, на русском.

| Страница (UA / EN) | Назначение |
|---|---|
| `/` · `/en/` | Холдинг: оба направления, цепочка ценности, форма заявки |
| `/it` · `/en/it` | Направление 01 — внедрение ERP |
| `/agro` · `/en/agro` | Направление 02 — агро-консалтинг, маркетплейсы, как работает закрытая площадка |
| `/join` · `/en/join` | **MVP:** анкета аграрного производителя (хозяйство + продукция) |
| `/market` · `/en/market` | **MVP:** закрытая витрина для покупателей по инвайт-коду, запрос на поставку |
| `/admin` | **MVP:** заявки, аграрии (верификация), запросы покупателей |

### Как работает MVP

1. Аграрий заполняет `/join` → статус `pending`.
2. Админ в `/admin` проверяет и ставит `verified` → предложения появляются на `/market`.
3. Покупатель с инвайт-кодом видит предложения (без контактов поставщика, только код `AG-XXXXXX`) и отправляет запрос.
4. Админ видит запрос с контактами обеих сторон и ведёт сделку (`new → in_progress → deal/lost`).

## Запуск

```bash
npm install
```

```bash
ADMIN_TOKEN=secret BUYER_INVITE_CODES=demo-buyer-2026 npm start
```

Открыть http://localhost:3000. Переменные — см. `.env.example`. Данные хранятся в `data/db.json` (в git не попадает).

## Ограничения MVP (осознанно)

- Хранилище — JSON-файл; для продакшена заменить на Postgres.
- Доступ по общему токену/инвайт-коду, без личных кабинетов.
- Нет уведомлений на email — заявки смотрим в `/admin`.
- Домен и email пока заглушки (`hello@agroai.example` в `BRAND`).
